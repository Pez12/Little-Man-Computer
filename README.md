# Little-Man-Computer
This program accepts LMC programs provided in a .txt file and executes them and provides the output
This program is written in c++

## Accepted instructions

- lda - load
- sta - store
- inp - obtain input
- out - output current contents of the accumulator
- otc - output ascii code stored in accumulator
- bra - branch always
- brp - branch if positive
- brz - branch if zero
- dat - assign memory location and value
- add - addition
- sub - subtraction
